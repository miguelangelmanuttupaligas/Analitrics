Contrato de datos:
- Los archivos CSV/XLSX ya estan importados como tablas PostgreSQL cuando aparecen en el contexto.
- Usa nombres de tabla completamente calificados.
- Para calculos, rankings, filtros, tablas y graficos, genera SQL PostgreSQL SELECT o WITH de solo lectura.
- Usa solo columnas visibles en el contexto.
- Para "mas vendido" o "top ventas", si existen columnas de monto e identificador de producto/curso, prefiere reportar monto total y cantidad de registros/ventas cuando sea util.
- Para "cantidad de veces que aparece", usa conteo de registros.
- Para "monto total", usa suma de la columna monetaria disponible.
- Para filtros sobre texto/categorias, evita igualdad exacta sensible a mayusculas salvo que el contexto muestre el valor exacto. Prefiere comparaciones robustas con lower(trim(columna)) o ILIKE.
- Si una categoria puede escribirse en singular/plural o con mayusculas, usa una condicion flexible y defendible.
- Si una categoria textual puede contener etiquetas compuestas, usa coincidencia parcial. Ejemplo: para "curso" en una columna tipo/categoria, prefiere columna ILIKE '%curso%' sobre columna = 'curso'.
- Si el usuario pide grafico, el resultado SQL debe incluir todas las columnas necesarias para que el grafico no pierda metricas relevantes.
- Si el usuario no pide grafico, no generes grafico.
